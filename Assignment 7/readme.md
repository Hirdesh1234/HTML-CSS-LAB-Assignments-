Experiment Title About Me Page
Aim Build a semantic About Me page with navigation links and an email contact link.
Software / Tools Required VS Code or text editor, web browser
Theory Semantic HTML elements such as header, nav, main, section, and footer describe page structure. Fragment links target element IDs. mailto links open an email application for the specified address.
Algorithm / Procedure
Create about-me.html with header, name heading, and About/Contact navigation.
Add a main section with id about, h2, and a short paragraph.
Add a footer with id contact and a mailto email link.
Replace placeholder name and email with personal details.
Program / Queries / Commands about-me.html
<title>About Me</title>
[Your Name]
About | Contact
About me
I am a student who enjoys learning technology, solving problems, and building useful projects.

Email: you@example.com

Input Name, biography, and email address are user-provided content.
