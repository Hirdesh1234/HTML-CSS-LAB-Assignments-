Experiment Title Sign-Up Forms and Choices
Aim Create labelled sign-up forms, radio choices, a course dropdown, and required fields.
Software / Tools Required VS Code or text editor, web browser
Theory The form element groups controls. Labels associate accessible text with inputs through for/id. Input types text, email, and password provide suitable controls. Radio buttons sharing a name are mutually exclusive. select and option create dropdowns; required enables browser validation.
Algorithm / Procedure
Create signup.html with name, email, and password fields and action thanks.html.
Create choices.html with Female/Male radio buttons and BCA/B.Tech dropdown.
Create signup-required.html with required name/email fields, name placeholder, and submit button.
Test required validation in the browser.
