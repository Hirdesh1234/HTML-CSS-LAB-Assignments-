EXPERIMENT NO. 2 Experiment Title Pushing and Cloning a Repository Aim Create a bare remote repository, push local commits, clone it, and inspect the cloned history. Software / Tools Required Git, VS Code terminal Theory A bare repository stores Git data without a working tree and can act as a remote. A remote name such as origin identifies a repository URL. Push transfers commits; clone creates a working copy with history. Algorithm / Procedure From html-lab, initialize a bare repository at ../html-remote. Add it as origin and verify with git remote -v. Push the current branch to origin. Move to the parent directory and clone html-remote as html-copy. Enter html-copy and inspect git log --oneline. Program / Queries / Commands Run these commands after completing Assignment 1 inside html-lab: git init --bare ../html-remote git remote add origin ../html-remote git remote -v git branch -M main git push origin main cd .. git clone html-remote html-copy cd html-copy git log --oneline If your branch is named master instead of main, use master consistently for the push. Input Local repository html-lab with commits from Experiment 1. Output Remote listing shows origin for fetch and push; push succeeds; cloned history contains the same commits.
