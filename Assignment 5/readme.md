Experiment Title Links and Images
Aim Link two HTML pages and display an image with dimensions and alternative text.
Software / Tools Required VS Code or text editor, web browser, image file
Theory The anchor element creates hyperlinks using href. Relative URLs link to files in the same project. The img element embeds an image; alt text provides an accessible description and fallback text. Width and height attributes specify rendered dimensions.
Algorithm / Procedure
Create home.html with heading, paragraph, and link to portfolio.html.
Create portfolio.html with a link back to home.html.
Place the instructor-provided image in images/ and update the image path.
Create portfolio-image.html with width and height 200 and descriptive alt text.
Program / Queries / Commands home.html
